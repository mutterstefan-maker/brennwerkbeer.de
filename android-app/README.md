# Brennwerk Beer Android-App

Die App zeigt `https://brennwerkbeer.de/` in einer sicheren Android-WebView. Dadurch sind die öffentliche Seite, Reservierungen und der Admin-Bereich ohne erneutes App-Update immer auf dem aktuellen Stand.

Bei Änderungen unter `android-app/` baut GitHub Actions automatisch eine installierbare APK. Sie liegt im jeweiligen Workflow-Lauf als Artefakt **Brennwerk-Beer-APK** bereit.
